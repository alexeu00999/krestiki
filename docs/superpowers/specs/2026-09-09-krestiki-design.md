# Крестики-нолики — дизайн

## Цель

Собрать локальную веб-игру «Крестики-нолики» для двух игроков на одном устройстве: она должна запускаться одной командой, хорошо выглядеть на телефоне и десктопе и давать понятную обратную связь после каждого хода.

## Пользовательский сценарий

1. Пользователь запускает `make run` и открывает `http://localhost:8000`.
2. На экране видны заголовок, текущий игрок, счёт `X/O`, поле 3×3 и кнопка новой партии.
3. Игрок нажимает свободную клетку; она получает его символ, ход переходит другому игроку.
4. После победы выигрышная линия подсвечивается, показывается сообщение о победителе, дальнейшие ходы блокируются.
5. Если заполнены все клетки без победителя, показывается ничья.
6. Кнопка новой партии очищает поле и сохраняет общий счёт; отдельная кнопка сброса счёта возвращает счёт к нулю.

## Архитектура

- Статическая страница без фреймворков, сборщика, npm и внешних запросов.
- `index.html` отвечает за семантическую разметку и доступные элементы управления.
- `style.css` отвечает за визуальную систему: тёмный фон, яркие акценты X/O, адаптивную сетку, состояния клеток и небольшие CSS-анимации.
- `app.js` хранит состояние партии, проверяет победу/ничью, обновляет DOM и обрабатывает клики/клавиатурный фокус.
- `Makefile` запускает встроенный сервер Python и выполняет статическую проверку обязательных файлов.

## Визуальное направление

Стиль — «ночная аркада»: графитовый фон, фиолетово-коралловый градиент, стеклянные панели, крупная типографика и заметная подсветка активного игрока. Основной акцент должен оставаться на игровом поле, без перегрузки декоративными элементами.

## Игровые правила и состояние

- Первый ход — `X`.
- Победные комбинации: три строки, три столбца и две диагонали.
- Состояние партии: массив из 9 значений, текущий игрок, статус (`playing`, `won`, `draw`), победная комбинация.
- Счёт хранится только в памяти страницы и не требует базы данных.
- Клавиша `R` начинает новую партию; клетка доступна с клавиатуры и имеет `aria-label`.

## Проверка готовности

- `make check` завершается успешно и проверяет наличие `index.html`, `style.css`, `app.js`, `Makefile`, `README.md`.
- `make run` поднимает сервер на порту 8000.
- В браузере можно сыграть победу X, победу O, ничью, новую партию и сброс счёта.
- Визуально проверены десктопная и узкая мобильная ширина.
- GitHub содержит историю коммитов и актуальную ветку `main`.
