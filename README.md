# Крестики × нолики

Небольшая локальная веб-игра для двух игроков на одном экране. Никаких npm, сборщиков и внешних сервисов: только HTML, CSS, JavaScript и встроенный сервер Python.

## Запуск

Нужен Python 3 и Make.

```bash
make check
make run
```

Откройте [http://localhost:8000](http://localhost:8000). Чтобы выбрать другой порт:

```bash
make run PORT=8080
```

Остановить сервер можно сочетанием `Ctrl+C`.

## Правила

- Первый ход всегда за игроком `X`.
- Побеждает тот, кто первым соберёт три своих символа в ряд, столбец или диагональ.
- Если свободных клеток не осталось и линии нет, фиксируется ничья.
- Кнопка «Новая партия» очищает поле, но сохраняет счёт.
- Кнопка «Сбросить счёт» обнуляет общий счёт.
- Клавиша `R` начинает новую партию.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка игрового экрана и доступные кнопки поля |
| `style.css` | Тёмная arcade-тема, состояния и адаптивная сетка |
| `app.js` | Состояние партии, проверка победы/ничьей и обновление интерфейса |
| `Makefile` | Локальный сервер и проверка обязательных файлов |

## Проверка JavaScript

Если установлен Node.js, синтаксис JavaScript можно проверить отдельно:

```bash
node --check app.js
```
